# AdSense 재심사 준비 계획

작성: 2026-09-08. 아래 계획 중 코드와 콘텐츠 구조로 처리할 수 있는 항목은 실행한다.
실제 AdSense 계정 설정·소유권 확인·재심사 제출은 운영자 계정에서 수행할 마지막 단계로 남긴다.
Google의 승인, 승인 확률, 기한은 보장하지 않는다. 아래 기준은 내부 검수 기준이며 Google의 공식 수량 기준이 아니다.

## 현재 실행 상태

- 학습·법적 페이지 14개를 빌드 시 정적 HTML로 사전 출력하고, 페이지별 title·description·canonical·Open Graph 메타를 넣었다.
- 지표별 학습 페이지에 고유한 이해 점검·반례·예시 답안을 추가했다.
- 학습 페이지 하단에 콘텐츠 검토일과 정정 문의 주소를 표시했다.
- 로컬 AdSense 설정의 예시 게시자 ID와 승인 플래그를 비활성 상태로 정리했다.
- 광고 요청과 미검토 자동 분석 화면은 기존 게이트로 계속 차단한다.
- 아직 실제 게시자 ID·ads.txt·Google 인증 CMP를 넣거나 AdSense 재심사를 제출하지 않았다.

## 진단 범위

- 사용자에게 통보된 거절 사유: 게시자 콘텐츠가 없는 화면, 가치가 낮은 콘텐츠.
- 구체적인 문제 URL과 심사 당시 렌더링 상태는 미확인이다. 자동 분석이라는 이유만으로 거절됐다고 단정하지 않는다.
- 현재 코드의 index.html은 빈 root에서 React를 실행한다. package.json에는 학습 페이지 사전 렌더링 단계가 없다. 정적 Hosting에서 제공하는 것과 본문이 정적 HTML에 포함되는 것은 다르다.
- 기존 학습 페이지와 설명 팝업을 기반으로 보완한다. 광고 비활성·404·sitemap 등 이전 완료 기록은 재구축하지 않고 재심사 직전에 검증한다.
- 이전에 제거한 게시자 ID가 실제 사용자 ID인지 확인 없이 예시라고 단정하지 않는다. 계정 화면과 대조 후 실제 메타 태그 및 ads.txt를 복원한다.

## 1. 계정과 접근 진단

- AdSense의 정확한 등록 URL, 최신 사유·문제 URL, 소유권·계정 설정 완료 여부를 기록한다.
- 실제 게시자 ID를 대조한다. 광고 송출과 독립적으로 공식 메타 태그 방식으로 소유권을 확인할 수 있다.
- 홈·학습 6개·방법론·운영 안내·분석·정책 페이지의 HTTP, 본문, 링크, robots, canonical을 점검한다.
- 브라우저 렌더링과 초기 HTML을 별도 확인한다. 검색 색인 여부는 진단 자료이며 승인 필수조건으로 취급하지 않는다.

## 2. 교육 콘텐츠 보강

- 기존 6개 지표 글마다 학습 목표, 원리, 직접 만든 그림, 단계별 해석, 반례, 연습문제와 해설, 출처, 실제 검토일을 포함한다.
- 우선 완성할 비교 수업: 구름 위인데 추세가 실패하는 경우, 밴드 상단 접촉과 추세 지속, RSI 과매수와 반전의 차이, 여러 추세 지표의 중복 근거, PBR 업종 비교와 적자·음수 자본의 한계, 점수와 상승 확률의 차이.
- 합성 예시는 실제 종목 데이터와 명확히 구별한다. 실제 데이터·차트는 해당 상품의 공개·출처 조건 확인 후 사용한다.
- 페이지 수나 글자 수를 늘리기 위한 반복 생성은 하지 않는다. 위 주제 수는 편집 범위이며 승인 최소 개수가 아니다.
- AI 초안과 자동 분석은 사람이 사실·계산·그림·출처를 검수한다. 실제 수행하지 않은 검수, 자격, 수익률을 표시하지 않는다.
- 완료 기준: 각 수업이 단독 URL로 질문 하나를 해결하고, 적용 과정과 실패 사례를 설명하며, 검토 기록이 남는다.

## 3. 학습 경로와 기술 제공

- 홈에서 입문 순서와 대표 수업 본문을 보여 주고, 수업 → 예제 → 연습 → 관련 분석으로 연결한다.
- 학습·방법론·운영·정책 본문을 빌드 시 HTML로 출력한다. 기존 콘텐츠 원본을 재사용하고 유료 SSR/Functions는 추가하지 않는다.
- URL별 제목·설명·canonical·내부 링크를 제공한다. 사용자와 수집기에 같은 콘텐츠를 제공한다.
- 학교 서버나 Firestore가 지연돼도 교육 본문은 읽을 수 있게 한다. 분석에는 데이터 기준일과 갱신 상태를 표시한다.
- 320/360/390/430/768/1024/1440px, 확대 200%, 터치·키보드·뒤로가기·팝업 포커스·가로 넘침을 검수한다.

## 4. 신뢰와 데이터 설명

- 운영 목적, 실제 작성·검토 주체, 정정 문의(or_not_official@naver.com), 업데이트 정책을 명시한다.
- 점수 산식·가중치·중복 근거·누락 데이터·분석 날짜를 설명한다. 상승 확률로 보이게 하는 표현을 제거한다.
- 개인정보 문구를 실제 로그인·분석·광고·후원 서비스의 작동과 일치시킨다.
- 금융서비스 규제 및 데이터 이용 권한은 AdSense 승인과 별도로 확인한다. 면책 문구만으로 적법성이 확보된다고 하지 않는다.

## 5. 광고와 동의

- 최초 광고 후보는 검수 완료 학습 상세 글이다. 자동 분석 결과·검색/빈 화면·로딩·오류·관리·동의 창·정책 페이지는 내부 운영 방침상 광고 제외한다.
- Google은 사이트 전체를 심사하므로 분석 화면에 광고가 없다고 그 콘텐츠 검토를 생략하지 않는다.
- 실제 게시자 ID, ads.txt, 슬롯, 자동광고 설정을 계정과 대조한다. ads.txt 파일과 CMP만으로 콘텐츠 품질 문제가 해결되지는 않는다.
- Google CMP의 동의/동의하지 않음/옵션 관리 구성을 우선 검토한다. 실제 게시·지역별 표시·거부·철회·광고 및 Analytics 동작을 확인한다.
- 커피 후원은 별도 표기하고 광고 클릭으로 후원하라는 문구, 오클릭 배치, 클릭·트래픽 구매를 배제한다.

## 6. 재심사 진입 조건과 운영

- 계정 연결 완료, 수업 검토 완료, 초기 HTML 본문 포함, 주요 URL 정상, 실제 모바일 검수 완료, 금지 화면 광고 요청 0, 데이터/개인정보 설명 일치가 모두 확인돼야 한다.
- 변경 파일·문제별 해결 근거·배포 URL·검수 일자를 남긴다. 비용 확인 후 Hosting만 배포한다.
- Google 안내의 일반 심사 기간은 며칠이며 경우에 따라 2~4주다. 승인 기한으로 약속하지 않는다.
- 재거절 시 새 사유와 URL을 대조하고 해당 문제를 보완한다. 내용 변경 없는 반복 신청은 작업 계획으로 삼지 않는다.
- 무료 한도 유지, DB 신규 의존성 없는 학습 콘텐츠, 제한된 배포 횟수를 원칙으로 한다.

## 역할

- 에이전트: 코드·콘텐츠 구조 진단, 수업 초안/도식/연습 설계, 정적 출력 설계, UI·광고 요청 검증표, 변경 근거 작성.
- 운영자: 실제 계정 정보 대조, 실제 운영자 정보 확인, 교육 내용 최종 검토, 데이터 권한 관련 증빙, AdSense 계정에서 재심사 제출.
