# AdSense 재심사 준비 계획

작성: 2026-09-08. 아래 계획 중 코드와 콘텐츠 구조로 처리할 수 있는 항목은 실행한다.
실제 AdSense 계정 설정·소유권 확인·재심사 제출은 운영자 계정에서 수행할 마지막 단계로 남긴다.
Google의 승인, 승인 확률, 기한은 보장하지 않는다. 아래 기준은 내부 검수 기준이며 Google의 공식 수량 기준이 아니다.

## 2026-10-01 현재 판정

2차 저가치 콘텐츠 점검과 후속 정확성 개선을 마쳤다. 사례 수업 8개 중 7개에 계산 규칙을 따르는 가상 수치 연습을 추가하고, V2의 120행 분석 기준과 개별 지표 누락 시 가중치 재정규화를 방법론·용어집과 일치시켰다. 승인된 Hosting-only 배포 뒤 라이브 18개 경로, 미등록 경로의 404, Search Console 확인 메타 태그 존재, 광고·Analytics 비활성 경계를 확인했다. 추가 점검에서 `/learn/lab`이 방향이 정해지지 않은 밴드 확장을 긍정 조건으로만 보여주는 문제를 찾아 양쪽 해석과 한계를 함께 설명하도록 수정하고 Hosting-only로 다시 배포했다. 재배포 후 라이브 검사 18개 경로가 실패 0건으로 통과했고, 실제 브라우저에서 밴드 확장을 선택해 가능한 해석과 방향상 한계가 동시에 표시됨을 확인했다. 실제 편집자 검토·금융 주제 작성자 정보·데이터 갱신 안정성·Search Console 속성 소유권·유기적 사용자 관심·AdSense 계정 정보는 확인되지 않았으므로 재심사 준비 완료로 보지 않는다. 상세 증거와 단계별 진입 조건은 [`ADSENSE_AUDIT_2026-10-01.md`](ADSENSE_AUDIT_2026-10-01.md)를 따른다.

- 볼린저 밴드 수축·확장·상단 접촉을 구별하고, 거래량 없는 돌파를 반례로 읽는 과정
- 이동평균의 위치와 기울기를 분리해 단기 회복과 중기 추세 전환을 구별하는 과정
- RSI 과열·침체·회복과 약세/강세 다이버전스를 같은 가격 장면에서 비교하는 과정
- 거래량을 절대값이 아니라 같은 종목의 평균과 비교하는 이유와 가격-거래량 충돌 사례
- 일목·이동평균·밴드가 같은 흐름을 말할 때 근거 중복을 세지 않는 방법
- 종합점수가 확률·수익률·순위가 아닌 내부 요약값인 이유와 점수 없는 해석 절차
- PBR·PER·ROE를 업종·이익의 질·부채와 함께 읽는 방법과 기술점수에서 제외한 이유
- 기준일·휴장일·데이터 부족·제공기관 지연을 확인하고 계산을 보류하는 방법
- 실제 공개 분석을 읽기 전에 합성 예시로 관찰→해석→반대 근거→확인 순서를 연습하는 방법

각 수업은 동일한 템플릿을 복사하지 말고 다음을 독립적으로 갖춘다.

- 학습자가 해결할 한 가지 질문과 학습 결과
- 운영자가 직접 만든 합성 숫자/도식/표와 계산 과정을 한 번 이상 보여 주기
- “이 조건의 뜻” → “그렇게 읽을 수 있는 이유” → “해석을 약하게 만드는 반대 조건” → “다음에 확인할 것”의 순서
- 실패 사례 또는 반례와 짧은 이해 점검, 정답 해설
- 계산 기준·데이터 출처·원시값을 공개하지 않는 범위·콘텐츠 검토일
- 관련 수업·용어집·방법론으로 이어지는 내부 링크

실제 종목의 가격·차트·API 응답을 가상 학습 예시처럼 포장하지 않는다. 공개 분석 결과는 운영자가 정한 규칙을 실제 데이터에 적용한 도구의 산출물로 설명하고, 가상 수치 연습은 별도 교육 예시라고 표시한다. AI 초안이 정적 수업에 사용되었다면 계산·표현·출처를 검토한 뒤 게시한다. 자동 갱신 결과 화면에 광고를 게재하려는 경우에는 직접 검토·선별 관련 게시자 정책을 별도로 충족해야 하며, 현재 /analysis에는 광고를 요청하지 않는다.

### 3단계 — 첫 방문자가 사이트의 독창적 가치를 즉시 이해하도록 재구성

- 홈 첫 화면에 대상 독자, 해결하려는 학습 문제, 3단계 이용 흐름(기초 수업 → 합성 사례 → 공개 분석 실습), 원시 시세를 재배포하지 않는 이유, 업데이트/정정 방법을 고유 문장으로 배치한다.
- `/learn`에는 강의 순서와 각 수업의 선수 지식·예상 학습 결과를 보여 준다. 단순 카드 목록을 반복하지 않는다.
- 모든 수업에 breadcrumb, 이전/다음 수업, 관련 사례, 용어집 링크를 넣어 탐색을 끊지 않는다.
- `/about`에는 실제 운영자/작성자 소개를 사용자가 제공한 사실만으로 작성한다. 자격·전문성·사용자 수·수익·검수 실적을 만들어 넣지 않는다.
- 이 사이트는 주식·가치지표를 다루므로 실제 작성 주체·금융 분야 경험·검토자를 확인한다. Google Search의 사용자 우선 콘텐츠 안내는 금융 안정성에 영향을 줄 수 있는 주제에서 신뢰 신호를 더 중시한다고 설명하지만, 이는 AdSense 별도 자격 요건이나 승인 보장이 아니다. 실제로 제공된 이름·경력·검토 기록만 공개하고, 확인되지 않은 전문가 검토를 주장하지 않는다.
- 방법론의 편집 이력은 실제 변경만 기록하고, 날짜만 갱신해 새 글처럼 보이게 하지 않는다.
- 후원·광고·정책 문구는 학습 본문과 분리하고, 광고를 보거나 클릭하면 도움이 된다는 표현을 사용하지 않는다.

### 4단계 — 동적 도구와 편집 콘텐츠의 경계를 더 선명하게 유지

- `/analysis`는 로그인 없이 실습할 수 있지만 `noindex,follow`, 광고 요청 0, 원시값·차트·개인화 조언 비공개를 유지한다.
- 자동 분석 목록 위에는 학습 안내를 두되, 그 안내가 자동 결과의 반복 설명으로 축소되지 않도록 합성 예시·읽는 순서·한계·관련 수업 링크를 유지한다.
- 종목별 상세 URL, 검색어 URL, 필터 조합 URL을 색인용 페이지로 만들지 않는다. 대량의 거의 같은 문장 페이지를 생성하지 않는다.
- 광고 후보는 사람이 편집·검토한 대표 수업 상세 페이지로 한정하고, 승인 전에는 기존처럼 광고·Analytics를 비활성 상태로 둔다.

### 5단계 — 운영 증거와 사용자 관심은 조작하지 않고 누적

- 새 수업의 작성일·검토일·수정 이유·정정 이력을 내부 문서와 페이지에 함께 남긴다.
- 공개 분석은 평일 새 기준일이 확인된 경우에만 갱신하고, 휴장일·제공기관 지연·서버 오류는 마지막 정상본과 함께 명시한다.
- Search Console의 색인/노출 오류와 실제 문의·정정 요청을 월별로 확인한다. 트래픽 구매, 클릭 교환, 가짜 후기, 자동 방문으로 “관심”을 만들지 않는다.
- Analytics는 Google 인증 CMP를 실제 게시하고 동의 전 로드 차단·철회 동작을 검증한 뒤에만 켠다. Analytics가 없다는 사실을 승인 실패 원인으로 단정하지 않는다.
- 200% 확대, 실제 휴대전화, 느린 네트워크에서 학습 본문이 읽히고 핵심 기능이 막히지 않는지 운영자가 확인한다.

### 재심사 제출을 보류하는 진입 조건

다음 조건이 모두 충족되기 전에는 “문제를 수정했습니다”를 선택하거나 재심사를 반복 제출하지 않는다.

1. `/`와 `/learn`의 중복 목적이 해소되고, 홈에서 사이트의 독창적 학습 가치가 초기 HTML로 이해된다.
2. 대표 학습 묶음 8~10개를 운영자가 직접 읽고 계산·출처·표현을 검토했으며, 각 수업에 합성 예시·반례·연습·내부 링크가 있다. 주식 정보를 다루는 작성·검토 주체와 경력은 실제 증빙이 있는 범위에서만 공개한다.
3. 자동 분석·검색·오류·관리·정책 화면에 광고 요청이 없고, 자동 결과가 색인용 대량 콘텐츠로 노출되지 않는다.
4. AdSense 등록 URL/게시자 ID/`ads.txt`가 계정 화면과 일치한다. CMP 선택은 Google의 사이트 연결 안내에서 심사 요청 후 단계로도 제시되므로, 실제 게시·지역별 동의 흐름은 재심사 자체의 필수 선행조건으로 단정하지 않는다. 다만 광고·Analytics 활성화 전에는 별도로 검증한다.
5. Search Console URL 검사, 초기 HTML, 모바일/200% 확대, 최신 공개 기준일의 증거를 `docs/` 실행 기록에 남긴다.
6. 사용자에게 제공하는 가치가 수치·페이지 수가 아니라 “특정 학습 질문을 독창적으로 해결하는 편집 수업”이라는 설명으로 일관된다.

이 조건은 승인 보장이 아니라 재심사 요청을 설명할 수 있는 최소 품질 게이트다. Google은 사이트 전체를 검토하며, 최종 판단과 검토 기간은 계정·크롤링 상태에 따라 달라진다.

- 콘텐츠 없는 화면 및 수동 검토 없는 자동 생성 콘텐츠 광고: https://support.google.com/publisherpolicies/answer/11112688
- 독창적 콘텐츠와 내비게이션: https://support.google.com/adsense/answer/7299563
- 사이트 전체 심사, 메타 태그 소유권 확인, 심사 기간: https://support.google.com/adsense/answer/7584263
- 지역별 Google 인증 CMP 요구사항: https://support.google.com/adsense/answer/13554020

Google 계정의 현재 심사 화면과 실제 모바일 화면은 이번 계획 수립에서 직접 확인하지 않았다. 웹 조회 도구의 사이트 접근 실패를 서비스 장애로 단정하지 않는다.
- 학교 서버 감시기는 최근 제공기관 `unchanged` 결과(아직 새 거래일 없음)를 실제 게시 실패와 구분한다. 감시기 누락·오래됨·`poll_failed` 상태는 계속 경고하며, 로컬 모니터 테스트 7건을 통과했다. 이 백엔드 변경은 학교 서버 동기화가 필요하고 Hosting-only 변경은 아니다.
- 공휴일성 `unchanged` 판정을 건강검사 직전에도 신뢰할 수 있도록 공개 API 감시 기본 종료 시각을 23시로 맞췄다. 이는 Firestore 호출을 추가하지 않으며, 실제 학교 서버의 cron 표현식은 운영자가 동기화해야 한다.
- 2026-09-29 Hosting 공개 분석을 브라우저에서 다시 확인한 결과 기준일은 2026-09-23이고 평일 기준 4일 경과 안내가 표시됐다. 화면이 지연 상태를 숨기지는 않지만, 최신 거래일로 갱신됐다는 증거는 아니므로 학교 서버 동기화 전에는 최신 데이터 운영을 완료로 표시하지 않는다.
