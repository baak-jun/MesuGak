# AdSense 저가치 콘텐츠 재심사 점검 — 2026-09-29

## 판정

**현 시점에 승인 가능성을 보장하거나 재심사 준비 완료라고 단정할 수 없다.** 공개 사이트의 접근성·정적 본문·내비게이션·광고 비활성 경계는 양호하다. 이전 거절 사유인 ‘가치가 별로 없는 콘텐츠’에 대해서는 지표별 글의 구체적인 계산·독창적인 학습 경험과 운영자 최종 검토 증거가 더 중요하다. 이번에 만든 예시는 Hosting에 배포됐지만 운영자 최종 편집 검토는 아직 남아 있다.

## 확인한 사실

- 2026-09-29 `npm run test:live`: 공개 18개 경로 모두 HTTP 200, 17개 작성 경로의 정적 본문·고유 메타데이터·canonical, `/analysis`의 `noindex`, 정적 광고 마크업 없음. `ads.txt`의 ID와 사이트 메타 태그의 ID는 서로 일치하지만 **실제 AdSense 계정의 ID와 일치하는지는 미확인**이다.
- 브라우저에서 `/`, `/learn`, `/learn/ichimoku`, `/about`, `/analysis`를 확인했다. 공개 분석은 비로그인 방문자에게 `30 / 915 종목`, 2026-09-28 기준일을 표시했다. 이는 오늘(2026-09-29) 기준 전 거래일 데이터로 보이지만 학교 서버의 cron·실패 복구를 증명하지는 않는다.
- 공개 수업은 그림·설명·반례·이해 점검을 갖고 있으나, 기존 배포본의 숫자 계산 과정은 제한적이었다. 새 가상 예시 6개를 추가하고 ‘읽은 뒤’ 퀴즈를 본문 뒤로 옮겨 Hosting에 배포했다.
- 로컬 `npm run lint`와 `npm run build`(콘텐츠·AdSense 사전검사 포함)가 통과했다. 390px 로컬 수업 미리보기에서 가로 넘침과 브라우저 오류 없이 퀴즈가 펼쳐졌다. 320px·200% 확대·실기기·느린 회선 검증은 이번 작업에서 완료하지 못했다.
- 공개 검색에서 `site:mesu-gak.web.app` 결과를 찾지 못했지만, 검색 결과의 부재만으로 실제 색인 상태를 확정할 수 없다. Search Console URL 검사로 확인해야 한다.
- 운영자 요청에 따라 Hosting 대상 `mesugak-target`만 다시 배포했다. 배포 후 `npm run test:live`에서 18개 경로 HTTP 200·광고 비활성·Analytics 비활성·분석 경로 `noindex`를 확인했다. 공개 브라우저에서 일목균형표와 볼린저 밴드의 새 계산 예시를 확인했고, 390px 폭에서 문서 가로 넘침은 없었다. 실기기·200% 확대·느린 회선 검증은 남았다.

## 남은 순서와 중단선

1. **운영자 편집 검토:** 여섯 가상 예시의 계산·표현·출처와 기존 문구의 ‘운영자가 직접 작성·검토’ 주장 사실성을 확인한다. 특히 실제 운영 경험·자격·성과를 임의로 추가하지 않는다.
2. **검증 배포 완료, 사람 검토 대기:** 운영자 요청으로 Hosting만 배포했다. Firestore·Functions·결제·광고 설정은 함께 배포하지 않았다. 대표 두 수업과 390px 폭은 확인했으며, 여섯 경로의 실제 모바일/PC 확인과 문장·계산 검토는 [운영자 체크리스트](ADSENSE_REVIEW_CHECKLIST.md)에 남겼다.
3. **계정 대조:** AdSense 등록 사이트 주소와 게시자 ID, 최신 거절 사유의 특정 URL, 현재 사이트 상태를 계정 화면에서 확인한다. Search Console의 홈·대표 수업 URL 검사에서 검색 접근과 색인 가능성을 확인한다.
4. **재심사 판단:** 위 증거를 갖춘 뒤 운영자가 ‘문제를 수정했습니다’를 선택한다. CMP 실게시 확인은 광고/Analytics 활성화 전 별도 필수 단계이며, 광고 게이트를 우회하지 않는다.

이 점검은 정책 적합성과 기술 상태를 살펴본 내부 기록일 뿐 Google 승인, 법적 적합성, 향후 트래픽을 보장하지 않는다.
